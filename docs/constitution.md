# Constitution - F1 Strategy Simulator

Non-negotiable principles. Every aspect, plan, and task must adhere to these.

1. **Simplicity first**: The code must be as simple as possible, without unnecessary complications.
2. **Functionality first**: The code must possess the functionality required to meet project requirements.
3. **Stability first**: The code must be stable and free of bugs or errors.
4. **Design principles**: The code must follow sound design and architectural principles.
5. **SOLID principles**: The code must adhere to SOLID principles to ensure maintainability and extensibility.
6. **Language**: The code must be in English and Spanish.
